<Heading>화면 흐름</Heading>

1. **홈**  
   상단 `TopNavLayout` ➜ 섹션별 `HomeSectionHeader` + 카드 컴포넌트  
   CTA는 `CampaignCard`, `PortfolioRowCard`, `ProductCard`로 이어집니다.

2. **목록**  
   `ListPageLayout` 위에 검색/필터 컴포넌트(`CampaignSearchSection`, `SearchInput`, `Filters`)를 조합하여 사용합니다.

3. **상세 & 지원**  
   `DetailPageLayout` 안에서 `DetailSection`, 카드, `CampaignApplyModal`이 순차적으로 배치됩니다.

4. **등록/폼**  
   `RegisterPageLayout` → `FormField`, `SectionContainer`, 입력 컴포넌트 세트 → 전송 버튼.

---

<Heading>스토리 작성 & 탐색 가이드</Heading>

- 모든 스토리는 프로젝트 테마(`ThemeProvider`, `GlobalStyle`)가 적용되어 실제 화면과 동일한 스타일을 보여줍니다.
- “Default / Variations / States” 구조를 따라 대표 케이스와 엣지 케이스를 문서화했습니다.
- 새 컴포넌트는 `stories.tsx` 파일에서 반드시 `argTypes`를 정의해 조작 가능한 API 문서를 제공합니다.
- Storybook은 `dev` 브랜치 푸시 시 자동 배포되며, `dev-sb.livbee.co.kr`에서 최신 문서를 확인할 수 있습니다.
